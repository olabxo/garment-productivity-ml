# Dataset
This project uses the **Productivity Prediction of Garment Employees** dataset from the UCI Machine Learning Repository.

Source: UCI Machine Learning Repository  
Licence: CC BY 4.0  
DOI: https://doi.org/10.24432/C51S6D

The dataset file used in this project is: `garments_worker_productivity.csv`

The CSV file is kept locally in the `data` folder and is not stored in this repository. It can be downloaded from the original UCI dataset page.
